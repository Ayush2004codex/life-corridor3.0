🔧 HOW IT WORKS - TECHNICAL DETAILS
═════════════════════════════════════════════════════════════════════════════

Real-Time Proximity Detection:
  
  For each animation frame (every 50ms):
    
    For each of the 6 signals:
      
      1. Calculate distance from ambulance to signal
         distance = √[(ambX - sigX)² + (ambY - sigY)²]
      
      2. Check if within threshold
         if (distance < 80 pixels):
           signal.color = GREEN 🟢
           signal.text = "GREEN"
         else:
           signal.color = RED 🔴
           signal.text = "RED"
      
      3. Update both map and control panel
         - SVG signal dots
         - Control indicators
         - Status text

Result: Realistic traffic signal behavior
