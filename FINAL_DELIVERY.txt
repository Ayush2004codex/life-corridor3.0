🚀 TECHNICAL IMPLEMENTATION
═════════════════════════════════════════════════════════════════════════════

Signal Behavior Algorithm:

  For every 50ms:
    
    ambulance_position = (x, y)
    
    For each of 6 signals:
      distance = √[(ambX - sigX)² + (ambY - sigY)²]
      
      if distance < 80 pixels:
        signal.color = GREEN 🟢
        signal.text = "GREEN"
      else:
        signal.color = RED 🔴
        signal.text = "RED"
      
      Update: map display + control panel
