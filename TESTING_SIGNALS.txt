═════════════════════════════════════════════════════════════════════════════

Problem: Don't see access denied
  → Make sure you're logged in as driver
  → Try admin.html, not admin
  → Clear cache (Ctrl+Shift+Del)
  → Check browser console (F12) for errors

Problem: Signal control not visible
  → Scroll down on driver dashboard
  → Should be between navigation and map
  → Make sure you're on driver.html
  → Clear browser cache

Problem: Signals don't turn green
  → Click "Activate Green Corridor" in form above
  → Check if button was actually clicked
  → Look at signal indicators (6 dots)
  → Check console for JavaScript errors

Problem: Admin dashboard still visible
  → Make sure you logged in as driver (not admin)
  → Check localStorage (F12 → Application)
  → Verify role is "driver" in session
  → Try logout and login again
