💻 HOW IT WORKS - TECHNICAL FLOW
═════════════════════════════════════════════════════════════════════════════

WHEN ADMIN CLICKS OVERRIDE:

  1. User clicks "⚡ Override All Green" button
  
  2. overrideAllSignalsGreen() function executes:
     a) Save to localStorage:
        {
          "lc_signal_override": {
            "active": true,
            "timestamp": 1609459200000
          }
        }
     
     b) Update DOM elements:
        - Loop through 6 signals
        - Change .signal-dot class from signal-red to signal-green
        - Change status text from "RED" to "GREEN"
     
     c) Show confirmation:
        - Button text: "✅ All Signals GREEN" (2 seconds)
        - Then revert to: "⚡ Override All Green"
  
  3. Browser storage event fires in driver tabs
  
  4. Driver's storage listener detects change:
     - Reads 'lc_signal_override' from localStorage
     - Calls overrideAllSignalsGreen()
  
  5. Driver view updates:
     - Changes all 6 signal colors to GREEN
     - Updates map signal indicators
     - Updates corridor status to "OVERRIDE ACTIVE"
     - Updates signal state emoji to 🟢

WHEN DRIVER PAGE LOADS:

  1. On page load, initialization function runs:
     - Reads localStorage for 'lc_signal_override'
     - Checks if override exists
  
  2. If found and timestamp < 60 seconds old:
     - Apply override immediately
     - Signals show GREEN
     - Corridor status shows "OVERRIDE ACTIVE"
  
  3. If older than 60 seconds or not found:
     - Signals show RED
     - Normal operation


🔌 DATA STRUCTURE
═════════════════════════════════════════════════════════════════════════════

localStorage Key: 'lc_signal_override'
Storage Type: JSON string

Value Structure:
{
  "active": true,        // boolean - is override active
  "timestamp": 1609459200000  // number - when override was set (ms)
}

Example:

🔧 TROUBLESHOOTING
═════════════════════════════════════════════════════════════════════════════

If driver signals don't update:
  1. Check browser console (F12) for errors
  2. Verify admin click was successful (signals turned GREEN in admin)
  3. Refresh driver page once
  4. Try again - signals should now be GREEN
  5. Check that both tabs are same origin (localhost, etc)

If override button doesn't work:
  1. Check console for JavaScript errors
  2. Verify you're logged in as admin
  3. Look for element: onclick="overrideAllSignalsGreen()"
  4. Hard refresh admin page (Ctrl+Shift+R)

If signals revert to RED immediately:
  1. Check if 60+ seconds have passed
  2. Driver may be running ambulance animation
  3. Refresh driver page to reset
  4. Try override again

If localStorage isn't working:
  1. Check browser privacy settings
  2. Enable localStorage if disabled
  3. Check for "Storage" tab in F12
  4. Try different browser
