🏗️ ARCHITECTURE
═════════════════════════════════════════════════════════════════════════════

COMMUNICATION METHOD: localStorage + storage event listener

Flow:
  1. Admin clicks "⚡ Override All Green" button
  2. Admin view turns all signals GREEN locally
  3. Function saves override state to localStorage:
     {
       active: true,
       timestamp: <current-time>
     }
  4. Driver view detects storage change event
  5. Driver view automatically turns all signals GREEN
  6. Corridor status updates to show override is active

SYNC MECHANISM:
  - Admin: Uses localStorage.setItem('lc_signal_override', ...)
  - Driver: Listens to 'storage' event for changes
  - Fallback: On page load, checks localStorage for recent override
  - Timeout: Override is considered active for 60 seconds
