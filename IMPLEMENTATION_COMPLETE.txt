🔧 HOW IT WORKS
═════════════════════════════════════════════════════════════════════════════

TECHNICAL FLOW:

1. Admin clicks "⚡ Override All Green" button
   ↓
2. JavaScript function executes:
   - Saves to localStorage: { active: true, timestamp: now }
   - Updates DOM: Changes all 6 signals to GREEN color
   - Shows confirmation on button for 2 seconds
   ↓
3. Browser fires storage event in driver tabs
   ↓
4. Driver's event listener detects change
   - Reads localStorage value
   - Calls overrideAllSignalsGreen()
   ↓
5. Driver view automatically updates:
   - All 6 signals turn GREEN
   - Map signals turn GREEN
   - Corridor status shows "OVERRIDE ACTIVE"
   - No page refresh needed!

FALLBACK:
- If driver page loads after override (within 60 seconds)
- Page initialization checks localStorage
- Applies override automatically on load

💻 TECHNICAL DETAILS
═════════════════════════════════════════════════════════════════════════════

Communication Method: Browser localStorage API
  • Cross-tab messaging via storage events
  • Instant updates when data changes
  • No server needed
  • Works in same origin (localhost, domain)

Data Structure:
  localStorage key: 'lc_signal_override'
  Value format: { active: true, timestamp: <milliseconds> }
  Persistence: 60 seconds (then expired)

Update Mechanism:
  • Admin: localStorage.setItem() - saves override
  • Driver: window.addEventListener('storage') - detects change
  • Fallback: Page load check with timestamp validation

No Dependencies:
  • Uses native browser APIs only
  • No external libraries required
  • No database needed
  • No server communication
