# Life Corridor v2.1 - Implementation Details

## Overview

**Life Corridor v2.1** implements realistic traffic signal behavior for an emergency ambulance routing system. The key innovation is **proximity-based signal activation** that mimics real-world green corridor systems in cities like Delhi and Kolkata.

---

## The Problem (User Request)

> "The particular signal should get green only when ambulance is near it, rest it should be red and even after ambulance crosses it, it should be red."

This required:
- ❌ NOT turning all signals green at once
- ✅ Each signal independent
- ✅ Signals turn GREEN only when ambulance is nearby
- ✅ Signals turn RED after ambulance passes

---

## Solution: Proximity Detection Algorithm

### How It Works

For each animation frame (every 50ms), the system:

```
FOR each of the 6 signals:
  1. Calculate Euclidean distance from ambulance to signal
  2. Check if distance < 80 pixels (proximity threshold)
  3. If near: Turn signal GREEN 🟢
  4. If far: Turn signal RED 🔴
  5. Update both map display and control panel
```

### Mathematical Calculation

```javascript
distance = √[(ambulanceX - signalX)² + (ambulanceY - signalY)²]

if (distance < 80) {
  signal.color = GREEN
} else {
  signal.color = RED
}
```

## Code Implementation

### Key Function: `animateAmbulance()`

Located in `driver.html` lines 355-456

```javascript
function animateAmbulance() {
  const amb = document.getElementById('ambGlowGroup');
  
  // Signal positions
  const signals = [
    {id: 1, x: 94, y: 154},
    {id: 2, x: 254, y: 154},
    {id: 3, x: 414, y: 154},
    {id: 4, x: 414, y: 74},
    {id: 5, x: 574, y: 74},
    {id: 6, x: 734, y: 74}
  ];
  
  const proximityThreshold = 80; // pixels
  let currentSegment = 0;
  let progress = 0;
  const speed = 0.005; // animation speed
  
  trackingInterval = setInterval(() => {
    progress += speed;
    
    // Get ambulance position
    const p1 = routePoints[currentSegment];
    const p2 = routePoints[currentSegment + 1];
    const cx = p1.x + (p2.x - p1.x) * progress;
    const cy = p1.y + (p2.y - p1.y) * progress;
    
    // Update ambulance on map
    amb.setAttribute('transform', `translate(${cx}, ${cy})`);
    
    // Check each signal
    signals.forEach(signal => {
      const distance = Math.sqrt(
        Math.pow(cx - signal.x, 2) + 
        Math.pow(cy - signal.y, 2)
      );
      
      if (distance < proximityThreshold) {
        // Turn GREEN
        setSignalGreen(signal.id);
      } else {
        // Turn RED
        setSignalRed(signal.id);
      }
    });
  }, 50); // Update every 50ms
}
```

### Signal State Update Functions

```javascript
function setSignalGreen(signalId) {
  const mapSignal = document.getElementById('ms' + signalId);
  const controlSignal = document.getElementById('sig' + signalId);
  const statusText = controlSignal?.parentElement?.querySelector('div:nth-child(3)');
  
  // Update map display
  if(mapSignal) mapSignal.setAttribute('fill', '#00c853'); // Green
  
  // Update control panel
  if(controlSignal) {
    controlSignal.style.background = '#00c853';
    controlSignal.style.boxShadow = '0 0 10px #00c853'; // Glow effect
  }
  
  // Update status text
  if(statusText) {
    statusText.textContent = 'GREEN';
    statusText.style.color = 'var(--g1)';
  }
}

function setSignalRed(signalId) {
  const mapSignal = document.getElementById('ms' + signalId);
  const controlSignal = document.getElementById('sig' + signalId);
  const statusText = controlSignal?.parentElement?.querySelector('div:nth-child(3)');
  
  // Update map display
  if(mapSignal) mapSignal.setAttribute('fill', '#ff4444'); // Red
  
  // Update control panel
  if(controlSignal) {
    controlSignal.style.background = '#ff4444';
    controlSignal.style.boxShadow = '0 0 10px #ff4444'; // Glow effect
  }
  
  // Update status text
  if(statusText) {
    statusText.textContent = 'RED';
    statusText.style.color = '#ff4444';
  }
}
```

## Performance Optimization

### Update Cycle
- **Frame Rate**: 50ms per update (20 FPS for signal logic)
- **Animation Speed**: 0.005 units per frame
- **Total Journey**: ~5 seconds (simulated)

### Distance Calculation
- Performed only when corridor is active
- Calculated once per frame per signal
- Uses efficient Euclidean distance

### Rendering
- Updates DOM only for color changes
- Uses CSS classes and inline styles
- Glow effects via box-shadow (hardware accelerated)

## Edge Cases Handled

### 1. Multiple Signals at Same Location
- Signals 2-3 at same Y coordinate (254, 414 vs 154 Y)
- Signals 5-6 at same Y coordinate (574, 734 vs 74 Y)
- Each signal checks independently → Works correctly

### 2. Signal Activation Order
- Signals activate based on proximity, not sequence
- Ambulance might be between two signals → both could be green temporarily
- System handles this naturally (distance-based check)

### 3. Arrival State
- When ambulance reaches hospital
- All signals reset to RED
- Counter shows 6/6
- Status shows "✅ Completed"

### 4. New Corridor Request
- User can activate another corridor
- Previous signals fully reset
- Counter resets to 0/6
- Animation restart works cleanly
