📊 REAL-TIME METRICS
═════════════════════════════════════════════════════════════════════════════

INFORMATION DISPLAYED:

1. Distance Left
   - Shows remaining distance in kilometers
   - Updates in real-time as ambulance moves
   - Example: 5.2 km → 0 km

2. ETA (Estimated Time of Arrival)
   - Countdown format: MM:SS
   - Updates every second
   - Example: 4:32 → 4:31 → ... → 0:00

3. Current Speed
   - Simulated speed between 40-45 km/h
   - Updates with random variation (realistic)
   - Shows current speed at any moment

4. Green Signals
   - Tracks how many signals are green as ambulance passes
   - Format: X/6 (signals passed / total signals)
   - Example: 0/6 → 1/6 → 2/6 ... → 6/6

5. Status
   - Shows ambulance ID and approach info
   - Example: "🚑 AMB-007 approaching... 45% progress"
   - Changes to "✅ Ambulance Arrived at Hospital" at end

💡 HOW IT WORKS (TECHNICAL)
═════════════════════════════════════════════════════════════════════════════

ROUTE DATA:
  - Total Distance: 5,200 meters (5.2 km)
  - Journey Time: 300 seconds (5 minutes)
  - Start Position: 20% left
  - End Position: 80% left (on map)

SIMULATION ALGORITHM:
  Progress: 0-100%
  
  For each 100ms:
    mapProgress += 1
    
    Ambulance Position:
      left = 20% + (progress * 0.6)
      
    Distance Left:
      km = 5.2 * (1 - progress/100)
      
    ETA:
      seconds = 300 * (1 - progress/100)
      display as MM:SS
      
    Speed:
      40-45 km/h with random variation
      
    Signals:
      count = floor(progress / 20)
      range: 0-5 signals

UPDATE FREQUENCY:
  - 100ms interval (10 updates per second)
  - Smooth visual experience
  - Real-time feeling

INTERACTION:
  - Click button to start/stop
  - Button text changes dynamically
  - Simulation runs independently
  - Can start another after completion
