Animation Algorithm:

  3. Calculate interpolated position

Signal Detection:
  • Uses Euclidean distance formula
  • Calculates distance from ambulance to each signal
  • If distance < 80: Signal turns GREEN
  • If distance >= 80: Signal turns RED
  • Updates happen in real-time
