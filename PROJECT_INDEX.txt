🔧 TECHNICAL SPECIFICATIONS
═════════════════════════════════════════════════════════════════════════════

See: v2.1_IMPLEMENTATION_DETAILS.md (complete technical details)

Session Management:
  → Storage: localStorage
  → Key: lc_session
  → Data: {loggedIn, name, email, role, loginTime}

Signal System:
  → Count: 6 traffic signals
  → Positions: Defined in driver.html (lines 366-373)
  → Activation: Proximity-based (< 80px threshold)
  → Update Rate: Every 50ms
  → Colors: Green (#00c853), Red (#ff4444)

Animation:
  → Speed: 0.005 units per frame
  → Total Journey: ~5 seconds
  → Update Cycle: 20 FPS for signals

Distance Calculation:
  → Formula: √[(ambX - sigX)² + (ambY - sigY)²]
  → Threshold: 80 pixels
  → Update: Real-time per frame
