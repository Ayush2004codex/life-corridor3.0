💻 TECHNICAL ARCHITECTURE
═════════════════════════════════════════════════════════════════════════════

COMMUNICATION PATTERN:
  Admin Browser                    Driver Browser
      ↓                                ↓
  admin.html                       driver.html
      ↓                                ↓
  localStorage                     localStorage
      ↓                                ↓
  storage event fired              storage event listener
      ↓                                ↓
  Driver page detects change  ← ← ← ← ← ← ← ← ← 
      ↓
  Auto-updates signals

STORAGE MECHANISM:
  Key: 'lc_signal_override'
  Value: {
    active: true,
    timestamp: <milliseconds>
  }
  Persistence: 60 seconds

ANIMATION SYSTEM:
  • SVG canvas rendering
  • JavaScript animation loop (50ms interval)
  • Proximity-based signal detection
  • Real-time DOM updates
  • Smooth interpolation between waypoints
