HOW IT WORKS:

  Start: [🔴] [🔴] [🔴] [🔴] [🔴] [🔴]

  Ambulance moves toward Signal 1...

  Near S1: [🟢] [🔴] [🔴] [🔴] [🔴] [🔴] ← Signal 1 GREEN!

  Passes S1: [🔴] [🔴] [🔴] [🔴] [🔴] [🔴] ← Signal 1 RED again!

  Near S2: [🔴] [🟢] [🔴] [🔴] [🔴] [🔴] ← Signal 2 GREEN!

  ... (continues for all 6 signals)

  End: [🔴] [🔴] [🔴] [🔴] [🔴] [🔴] ✅ Arrived


ALGORITHM:

  distance = √[(ambulanceX - signalX)² + (ambulanceY - signalY)²]

  if distance < 80 pixels:
    signal = GREEN 🟢
  else:
    signal = RED 🔴

🚨 TROUBLESHOOTING
═════════════════════════════════════════════════════════════════════════════

Problem: Signals not changing color
  → Clear browser cache (Ctrl+Shift+Del)
  → Hard refresh (Ctrl+Shift+R)
  → Make sure corridor is activated

Problem: All signals turn green at once
  → You're using old version
  → Ensure driver.html is updated to v2.1
  → Clear cache and refresh

Problem: Can't login
  → Check email spelling
  → Verify password is correct
  → Try demo accounts: admin@lifecorridor.io or driver@lifecorridor.io

Problem: Access denied not showing
  → Make sure you're logged in as driver
  → Try accessing admin.html directly
  → Check browser console for errors

Problem: Signals not syncing between map and panel
  → Refresh page
  → Hard refresh with Ctrl+Shift+R
  → Close and reopen browser tab
