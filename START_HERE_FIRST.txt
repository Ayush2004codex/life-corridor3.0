🎬 THE SIGNAL BEHAVIOR EXPLAINED (SIMPLE VERSION)
═════════════════════════════════════════════════════════════════════════════

How It Works:

  1. You activate corridor
  2. Ambulance starts moving on map
  3. For each traffic signal:
     a. System calculates: How far is ambulance from this signal?
     b. If close (< 80 pixels): Signal turns GREEN 🟢
     c. If far (> 80 pixels): Signal turns RED 🔴
  4. This happens in real-time
  5. Result: Signals change as ambulance moves past them

Why It's Cool:

  ✨ Matches how real traffic works
  ✨ Looks professional
  ✨ Demonstrates technical skill
  ✨ Engaging to watch
  ✨ Educational

That's It!

  The algorithm is simple but effective:
  Distance = √[(ambulanceX - signalX)² + (ambulanceY - signalY)²]
  If distance < 80 pixels → GREEN
  Else → RED
