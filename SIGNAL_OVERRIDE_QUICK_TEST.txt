⚠️ COMMON ISSUES & SOLUTIONS
═════════════════════════════════════════════════════════════════════════════

Issue: Driver signals don't update automatically
  Solution: 
    - Check browser console (F12) for errors
    - Signals should update within 1 second
    - If not, refresh driver page
    - Check that admin click happened successfully

Issue: Button shows no confirmation message
  Solution:
    - Button should show "✅ All Signals GREEN" for 2 seconds
    - If not showing, check browser console
    - Make sure you're clicking the right button

Issue: Signals go back to RED immediately
  Solution:
    - If override is set and corridor is NOT active
    - Signals may reset when ambulance animation completes
    - Try activating corridor first, then override

Issue: Different color in different tabs
  Solution:
    - localStorage might have caching issues
    - Hard refresh (Ctrl+Shift+R) on driver tab
    - Check that both tabs are from same origin (localhost/domain)

Issue: Works in one browser but not another
  Solution:
    - localStorage is browser-specific
    - Cross-browser sync via storage event might not work
    - Each browser tab needs separate test
    - This is normal browser behavior
