🔧 TECHNICAL DETAILS
═════════════════════════════════════════════════════════════════════════════

URL PARAMETER HANDLING:
  index.html → goToSignIn() → login.html?tab=signin
  index.html → goToSignUp() → login.html?tab=signup
  
  login.html detects URL parameter automatically
  Switches tab on page load
  User sees correct form immediately

FUNCTION CALLS:
  goToSignIn()  → Sets location to login.html?tab=signin
  goToSignUp()  → Sets location to login.html?tab=signup

AUTO-TAB SWITCHING:
  On login.html page load:
  → Checks URL for 'tab' parameter
  → Calls switchAuthTab() with correct tab
  → User sees Sign In or Sign Up form
